=====================================================================
 APU কমিউনিটি — সবার জন্য চালু করার নিয়ম (Firebase, বিনামূল্যে)
=====================================================================

কী কী ফাইল বদলেছে:
  • app.js          → নতুন ফাইল দিয়ে পুরোনোটা বদলান
  • firestore.rules → Firebase-এ পেস্ট করতে হবে (ওয়েবসাইটে আপলোড করার দরকার নেই)
  • config.js       → শুধু নিচের ধাপ ৫-এ Firebase-এর তথ্য বসাবেন
  • বাকি ফাইল (index.html, community.css, logo.png) আগের মতোই

---------------------------------------------------------------------
ধাপ ১: Firebase প্রজেক্ট খুলুন
---------------------------------------------------------------------
  1. https://console.firebase.google.com খুলে Google অ্যাকাউন্টে ঢুকুন
  2. "Create a project" (বা "Add project") চাপুন, নাম দিন: apu-community
  3. Google Analytics বন্ধ রাখুন (দরকার নেই) → Create project

ধাপ ২: ইমেইল-পাসওয়ার্ড লগইন চালু করুন
---------------------------------------------------------------------
  1. বাঁ পাশে Build → Authentication → Get started
  2. Sign-in method ট্যাবে "Email/Password" চাপুন
  3. প্রথম সুইচটি (Enable) অন করে Save দিন

ধাপ ৩: ডেটাবেস খুলুন
---------------------------------------------------------------------
  1. Build → Firestore Database → Create database
  2. Location: asia-south1 (Mumbai) বা asia-southeast1 (Singapore) বেছে নিন
     (★ পরে বদলানো যায় না)
  3. "Start in production mode" বেছে Create চাপুন

ধাপ ৪: নিরাপত্তা নিয়ম (Rules) বসান — সবচেয়ে জরুরি ধাপ
---------------------------------------------------------------------
  1. Firestore Database পাতার ওপরে "Rules" ট্যাবে যান
  2. আগের সব লেখা মুছে firestore.rules ফাইলের পুরো লেখা পেস্ট করুন
  3. "Publish" চাপুন

ধাপ ৫: config.js-এ তথ্য বসান
---------------------------------------------------------------------
  1. ওপরে বাঁ দিকে ⚙️ (Project settings) → General → নিচে "Your apps"
  2. "</>" (Web) আইকন চাপুন → নাম দিন apu-web → Register app
     (Firebase Hosting টিক দেওয়ার দরকার নেই)
  3. যে firebaseConfig দেখাবে তার apiKey, authDomain, projectId, appId
     কপি করে config.js-এর firebase অংশে PASTE... লেখাগুলোর জায়গায় বসান।
     (apiKey গোপন কিছু না, ওয়েবসাইটে থাকাই নিয়ম — সুরক্ষা দেয় ধাপ ৪-এর Rules)

ধাপ ৬: আপনার ওয়েবসাইটের ঠিকানা অনুমোদন করুন
---------------------------------------------------------------------
  1. Authentication → Settings → Authorized domains → Add domain
  2. যেখানে সাইট হোস্ট করেছেন সেই ঠিকানা দিন (যেমন: yourname.github.io
     বা yoursite.netlify.app বা আপনার নিজস্ব ডোমেইন; https:// ও / ছাড়া)
  এটা না করলে লগইনে "unauthorized domain" ভুল আসবে।

ধাপ ৭: ফাইল আপলোড করে নিজে আগে নিবন্ধন করুন
---------------------------------------------------------------------
  1. community ফোল্ডারের ফাইলগুলো (নতুন app.js ও config.js সহ) হোস্টিংয়ে আপলোড করুন
  2. ★ লিংক কাউকে দেওয়ার আগে নিজে "নতুন অ্যাকাউন্ট" খুলুন
     → আপনিই প্রথম, তাই আপনি স্বয়ংক্রিয়ভাবে অ্যাডমিন হবেন
     (পরে কেউ আর অ্যাডমিন হতে পারবে না — Rules তা আটকে দেয়)
  3. এরপর লিংক শেয়ার করুন। নতুন সদস্যরা নিবন্ধন করলে "অ্যাডমিন" মেনুতে
     গিয়ে "অনুমোদন" চাপুন।

---------------------------------------------------------------------
জেনে রাখুন
---------------------------------------------------------------------
  • ডেমো মোডে আগে যা পোস্ট/অ্যাকাউন্ট করেছিলেন তা শুধু সেই ব্রাউজারে ছিল;
    আসল মোডে সেগুলো আসবে না — নতুন করে শুরু হবে।
  • বিনামূল্যের প্ল্যানে প্রতিদিন প্রায় ৫০,০০০ রিড ও ২০,০০০ রাইট এবং ১ GB স্টোরেজ।
    ছবি ডেটাবেসেই জমা হয় (ছোট করে), তাই অনেক ছবি হলে স্টোরেজ আগে ভরবে।
  • সব সদস্য একে অপরের ইমেইল ডেটাবেসে পড়তে পারে (অ্যাপের পর্দায় ইমেইল শুধু অ্যাডমিন প্যানেলে দেখায়)।
  • অ্যাডমিন বদলাতে চাইলে Firestore Database → users → ব্যবহারকারীর ডকুমেন্টে
    role = admin করুন (Console থেকে Rules প্রযোজ্য হয় না, তাই এটা কেবল আপনিই পারবেন)।
  • ভুল হলে ব্রাউজারে F12 → Console দেখুন; "অনুমতি নেই" মানে ধাপ ৪ ঠিকমতো Publish হয়নি।
